## Introduction

JKT48Connect is a **REST API framework** designed to provide fast, flexible, and comprehensive data related to JKT48, powered by a robust backend.

JKT48Connect has different parts:

<Cards>

<Card icon={<CpuIcon className="text-purple-300" />} title='API Core'>

Handles most of the API logic, including data retrieval, filtering, and ensuring high performance.

</Card>

<Card icon={<PanelsTopLeft className="text-blue-300" />} title='API Endpoints'>

The various endpoints offered by JKT48Connect provide structured access to JKT48 data.

</Card>

<Card icon={<Database />} title='Data Source'>

The source of our JKT48 data, constantly updated to ensure accuracy and freshness.

</Card>

<Card icon={<Terminal />} title='Client SDKs (Coming Soon)'>

### Terminology

**REST API:** Representational State Transfer Application Programming Interface. JKT48Connect provides data through a RESTful interface.

Although not required, some basic knowledge of making HTTP requests would be useful for further customisations and integration.

## Getting Started

A minimum version of Node.js 18 is recommended for interacting with the API.

<Tabs groupId='example-usage' persist items={['Fetch API', 'Axios', 'cURL']} label='Example API Call'>

```javascript tab="Fetch API"
// Example: Get a list of all members
fetch('[https://v2.jkt48connect.my.id/api/jkt48/members](https://v2.jkt48connect.my.id/api/jkt48/members)')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error('Error:', error));

// Example: Get a list of all members
const axios = require('axios');

axios.get('[https://v2.jkt48connect.my.id/api/jkt48/members](https://v2.jkt48connect.my.id/api/jkt48/members)')
  .then(response => {
    console.log(response.data);
  })
  .catch(error => {
    console.error('Error:', error);
  });

FAQ
Some common questions you may encounter.
<Accordions>
<Accordion id='base-url' title="What is the base URL for the API?">
The base URL for all JKT48Connect API requests is https://v2.jkt48connect.my.id. All endpoint paths should be appended to this base URL.
export const API_BASE_URL = '[https://v2.jkt48connect.my.id](https://v2.jkt48connect.my.id)'; // [!code highlight]

</Accordion>
<Accordion id='performance' title="Is the API performant?">

Yes, JKT48Connect API is designed for performance, utilizing efficient data retrieval methods and caching strategies to ensure quick response times.
</Accordion>
<Accordion id='custom-requests' title='How to make specific requests (e.g., filter by generation)?'>

The API supports various query parameters for filtering and customizing requests. Please refer to the API Endpoints Reference for detailed information on available parameters for each endpoint.
For example, to get members from a specific generation:
[https://v2.jkt48connect.my.id/members?generation=10](https://v2.jkt48connect.my.id/members?generation=10)

</Accordion>

<Accordion id='multiple-data-sources' title="Can I combine data from different endpoints?">
    Yes, you can combine data from different endpoints in your application logic to build richer features.
</Accordion>

</Accordions>
