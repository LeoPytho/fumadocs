## What is Members API?

The Members API from @jkt48/core allows you to retrieve comprehensive information about all JKT48 members. This endpoint provides detailed member data including profiles, social media links, generation information, and current status in a single API call.

- Complete member profiles with nicknames
- Social media account links (Twitter, Instagram, TikTok, SHOWROOM, IDN)
- Generation and group information
- Profile images and alternative images
- Graduate status tracking
- SHOWROOM integration data

<Callout>
This API endpoint returns data for all active and graduated JKT48 members, providing a comprehensive overview of the entire roster.

All features require an API key for authentication and access.
</Callout>

## Data Field Explanations

<Accordions type="single">

<Accordion title="Basic Information">
- **_id**: Unique identifier for the member
- **name**: Full name of the member
- **nicknames**: Array of known nicknames or stage names
- **url**: URL-friendly identifier for the member
- **group**: Group affiliation (e.g., "jkt48")
</Accordion>

<Accordion title="Images & Media">
- **img**: Primary profile image URL (usually from SHOWROOM)
- **img_alt**: Alternative profile image URL (high-quality version)
</Accordion>

<Accordion title="Social Media">
- **socials**: Array of social media accounts with platform titles and URLs
- **idn_username**: IDN Live platform username
</Accordion>

<Accordion title="Status & Generation">
- **generation**: Member's generation (e.g., "gen12-jkt48")
- **is_graduate**: Boolean indicating if the member has graduated
- **sr_exists**: Boolean indicating SHOWROOM account existence
- **room_id**: SHOWROOM room identifier
</Accordion>

</Accordions>

## Advanced Examples

### Processing All Members Data

```javascript
const jkt48Api = require('@jkt48/core');

async function processMembers() {
  try {
    const apiKey = 'your-api-key-here';
    const members = await jkt48Api.members(apiKey);
    
    // Filter active members only
    const activeMembers = members.filter(member => !member.is_graduate);
    
    console.log(`Total members: ${members.length}`);
    console.log(`Active members: ${activeMembers.length}`);
    
    // Group by generation
    const byGeneration = {};
    members.forEach(member => {
      if (!byGeneration[member.generation]) {
        byGeneration[member.generation] = [];
      }
      byGeneration[member.generation].push(member);
    });
    
    console.log('Members by generation:', byGeneration);
  } catch (error) {
    console.error('Error fetching members:', error.message);
  }
}
```

### Extract Social Media Links

```javascript
async function getMemberSocialMedia() {
  try {
    const apiKey = 'your-api-key-here';
    const members = await jkt48Api.members(apiKey);
    
    members.forEach(member => {
      console.log(`\n${member.name} (${member.nicknames.join(', ')})`);
      
      member.socials.forEach(social => {
        console.log(`  ${social.title}: ${social.url}`);
      });
    });
  } catch (error) {
    console.error('Error fetching member social media:', error.message);
  }
}
```

### Find Specific Member

```javascript
async function findMember(searchName) {
  try {
    const apiKey = 'your-api-key-here';
    const members = await jkt48Api.members(apiKey);
    
    const member = members.find(m => 
      m.name.toLowerCase().includes(searchName.toLowerCase()) ||
      m.nicknames.some(nick => nick.toLowerCase().includes(searchName.toLowerCase()))
    );
    
    if (member) {
      console.log('Found member:', member);
    } else {
      console.log('Member not found');
    }
  } catch (error) {
    console.error('Error searching for member:', error.message);
  }
}

// Usage
findMember('Aralie');
```
