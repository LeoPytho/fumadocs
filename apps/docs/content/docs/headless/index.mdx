## What is this?

@jkt48/core is a powerful Node.js module created by JKT48Connect to simplify developers' work when building JKT48-related projects. This module serves as an alternative to using REST API URLs directly, providing a more streamlined and developer-friendly approach.

- Member Management & Information
- Schedule & Event Handling
- News & Announcements
- Theater Show Data
- Social Media Integration
- Additional utilities for JKT48 ecosystem

<Callout title="Info">

    This entire ecosystem project was created by **Valzy** as the main developer, working independently to build comprehensive tools for the JKT48 community.

    All features require an API key for authentication and access.

</Callout>

## Basic Usage

Here's a simple example of how to use the @jkt48/core module:

<Tabs items={['CommonJS', 'ES Modules']}>
<Tab>

## Advanced Examples

### Getting Member Details

```javascript
const jkt48Api = require('@jkt48/core');

async function getMemberDetails(memberId) {
  try {
    const apiKey = 'your-api-key-here';
    const memberInfo = await jkt48Api.memberDetails(apiKey, memberId);
    
    console.log(`Name: ${memberInfo.name}`);
    console.log(`Generation: ${memberInfo.generation}`);
    console.log(`Social Media: ${memberInfo.socialMedia}`);
  } catch (error) {
    console.error('Error fetching member details:', error.message);
  }
}
```

### Fetching Theater Schedule

```javascript
async function getTheaterSchedule() {
  try {
    const apiKey = 'your-api-key-here';
    const schedule = await jkt48Api.theaterSchedule(apiKey);
    
    schedule.forEach(show => {
      console.log(`Show: ${show.title}`);
      console.log(`Date: ${show.date}`);
      console.log(`Members: ${show.members.join(', ')}`);
    });
  } catch (error) {
    console.error('Error fetching schedule:', error.message);
  }
}
```

<Callout title="Tip">

    Always handle errors properly when making API calls to ensure your application remains stable.

</Callout>
