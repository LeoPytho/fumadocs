## What is Recent Live API?

The Recent Live API from `@jkt48/core` allows you to retrieve the latest live stream activity from JKT48 members. This includes both SHOWROOM and IDN Live sessions with detailed information such as member profile, duration, viewers, and total gifts.

- Latest live streams from all platforms
- Includes member details (profile, nickname, graduation status)
- Gift, points, and viewer stats
- Support for both official and individual member rooms

<Callout>
You can use this endpoint to track real-time or recent member live streaming activity. Data is updated frequently.
</Callout>

<AutoTypeTable>

```ts

  _id: string;

  room_id: number;
  points: number;
```

## Advanced Example: Print Summary of Recent Lives

```javascript
import { recent } from '@jkt48/core';

async function showRecentLives() {
  const apiKey = 'your-api-key-here';
  const recentLives = await recent(apiKey);

  recentLives.forEach(live => {
    const { name, nickname } = live.member;
    const platform = live.type.toUpperCase();
    const duration = Math.round(live.live_info.duration / 60000); // convert ms to minutes
    console.log(`${name} (${nickname}) streamed on ${platform} for ${duration} minutes.`);
  });
}

showRecentLives();
```
