## What is Recent Live API?

The Recent Live API from @jkt48/core allows you to retrieve comprehensive information about the most recent JKT48 live streams. This endpoint provides detailed live streaming data including member information, viewer statistics, gift earnings, and streaming duration from both SHOWROOM and IDN platforms.

- Recent live streaming sessions from all members
- Viewer count and engagement statistics
- Gift earnings and points data
- Stream duration and timing information
- Member profile integration
- Multi-platform support (SHOWROOM & IDN)

<Callout>
This API endpoint returns the most recent live streaming data from JKT48 members, providing real-time insights into streaming activities and audience engagement.

All features require an API key for authentication and access.
</Callout>

## Data Field Explanations

<Accordions type="single">

<Accordion title="Basic Information">
- **_id**: Unique identifier for the live stream record
- **data_id**: Platform-specific data identifier
- **type**: Platform type ("showroom" or "idn")
- **created_at**: Timestamp when the stream ended
</Accordion>

<Accordion title="IDN Platform Data">
- **idn.id**: IDN Live stream unique identifier
- **idn.username**: IDN Live username
- **idn.slug**: URL slug for the stream
- **idn.title**: Stream title
- **idn.image**: Stream thumbnail image
</Accordion>

<Accordion title="Member Information">
- **member.name**: Full name of the streaming member
- **member.nickname**: Short nickname
- **member.img**: Profile image URL
- **member.img_alt**: Alternative profile image
- **member.url**: URL-friendly identifier
- **member.is_graduate**: Graduation status
- **member.is_official**: Official account status
</Accordion>

<Accordion title="Live Stream Statistics">
- **live_info.duration**: Stream duration in milliseconds
- **live_info.viewers.num**: Peak viewer count
- **live_info.viewers.is_excitement**: Excitement status indicator
- **live_info.date.start**: Stream start timestamp
- **live_info.date.end**: Stream end timestamp
</Accordion>

<Accordion title="Financial Data">
- **gift_rate**: Gift conversion rate
- **room_id**: Platform room identifier
- **points**: Points earned during stream
- **total_gift**: Total gift earnings in formatted currency
</Accordion>

</Accordions>

## Advanced Examples

### Processing Recent Live Data

```javascript
const jkt48Api = require('@jkt48/core');

async function analyzeRecentStreams() {
  try {
    const apiKey = 'your-api-key-here';
    const recent = await jkt48Api.recent(apiKey);
    
    // Sort by viewer count
    const sortedByViewers = recent.sort((a, b) => 
      b.live_info.viewers.num - a.live_info.viewers.num
    );
    
    console.log('Top 5 streams by viewers:');
    sortedByViewers.slice(0, 5).forEach(stream => {
      console.log(`${stream.member.nickname}: ${stream.live_info.viewers.num} viewers`);
    });
    
    // Calculate total earnings
    const totalEarnings = recent.reduce((sum, stream) => {
      const earnings = parseFloat(stream.total_gift.replace(/[^\d]/g, '')) || 0;
      return sum + earnings;
    }, 0);
    
    console.log(`Total earnings: Rp ${totalEarnings.toLocaleString()}`);
  } catch (error) {
    console.error('Error analyzing streams:', error.message);
  }
}
```

### Filter by Platform

```javascript
async function getStreamsByPlatform(platform) {
  try {
    const apiKey = 'your-api-key-here';
    const recent = await jkt48Api.recent(apiKey);
    
    const filteredStreams = recent.filter(stream => stream.type === platform);
    
    console.log(`${platform.toUpperCase()} streams:`);
    filteredStreams.forEach(stream => {
      const duration = Math.round(stream.live_info.duration / 60000); // Convert to minutes
      console.log(`${stream.member.nickname}: ${duration} minutes, ${stream.live_info.viewers.num} viewers`);
    });
  } catch (error) {
    console.error('Error filtering streams:', error.message);
  }
}

// Usage
getStreamsByPlatform('showroom');
getStreamsByPlatform('idn');
```

### Stream Duration Analysis

```javascript
async function analyzeDuration() {
  try {
    const apiKey = 'your-api-key-here';
    const recent = await jkt48Api.recent(apiKey);
    
    const durations = recent.map(stream => ({
      member: stream.member.nickname,
      duration: Math.round(stream.live_info.duration / 60000), // minutes
      viewers: stream.live_info.viewers.num
    }));
    
    // Sort by duration
    durations.sort((a, b) => b.duration - a.duration);
    
    console.log('Longest streams:');
    durations.slice(0, 5).forEach(stream => {
      console.log(`${stream.member}: ${stream.duration} minutes (${stream.viewers} viewers)`);
    });
    
    // Average duration
    const avgDuration = durations.reduce((sum, s) => sum + s.duration, 0) / durations.length;
    console.log(`Average stream duration: ${Math.round(avgDuration)} minutes`);
  } catch (error) {
    console.error('Error analyzing duration:', error.message);
  }
}
```

### Real-time Stream Monitor

```javascript
async function monitorStreams() {
  try {
    const apiKey = 'your-api-key-here';
    
    setInterval(async () => {
      const recent = await jkt48Api.recent(apiKey);
      
      // Find streams that ended in the last 10 minutes
      const tenMinutesAgo = new Date(Date.now() - 10 * 60 * 1000);
      const recentEnded = recent.filter(stream => 
        new Date(stream.created_at) > tenMinutesAgo
      );
      
      if (recentEnded.length > 0) {
        console.log(`${recentEnded.length} streams ended recently:`);
        recentEnded.forEach(stream => {
          console.log(`- ${stream.member.nickname} (${stream.type}): ${stream.live_info.viewers.num} viewers`);
        });
      }
    }, 60000); // Check every minute
  } catch (error) {
    console.error('Error monitoring streams:', error.message);
  }
}
```
