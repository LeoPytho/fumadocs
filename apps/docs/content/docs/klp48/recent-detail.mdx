## What is Recent Detail API?

The Recent Detail API from @jkt48/core allows you to retrieve comprehensive detailed information about a specific JKT48 live stream using its unique identifier. This endpoint provides extensive live streaming data including member information, complete gift logs, viewer statistics, user interactions, comments data, and screenshot captures from both SHOWROOM and IDN platforms.

- Complete live stream details with full member profile
- Comprehensive gift transaction logs with timestamps
- Detailed viewer and comment statistics
- User interaction data with avatars and comment counts
- Screenshot captures throughout the stream
- Full IDN platform integration data
- Stream timing and duration information

<Callout>
This API endpoint returns detailed information about a specific live stream session, providing in-depth insights into streaming activities, audience engagement, and financial metrics.

All features require an API key for authentication and access.
</Callout>

## Data Field Explanations

<Accordions type="single">

<Accordion title="Basic Stream Information">
- **author**: Data source author information
- **data_id**: Unique data identifier for the stream
- **live_id**: Unique live stream identifier
- **room_id**: Platform room identifier
- **created_at**: Stream end timestamp
- **type**: Platform type ("showroom" or "idn")
</Accordion>

<Accordion title="Room & Member Information">
- **room_info.name**: Full member name with Japanese characters
- **room_info.nickname**: Short display name
- **room_info.fullname**: Complete real name
- **room_info.img**: Profile image URL
- **room_info.img_alt**: Alternative high-quality image
- **room_info.jikosokai**: Member self-introduction
- **room_info.generation**: Member generation
- **room_info.group**: Group affiliation
</Accordion>

<Accordion title="IDN Platform Data">
- **idn.id**: IDN Live stream unique identifier
- **idn.username**: IDN Live username
- **idn.slug**: URL slug for the stream
- **idn.title**: Stream title
- **idn.image**: Stream thumbnail image
</Accordion>

<Accordion title="Gift & Financial Data">
- **total_gifts**: Total gift points received
- **gift_rate**: Gift conversion rate
- **live_info.gift.log**: Detailed gift transaction log per user
- **live_info.gift.list**: Summary of all gift types received
- **live_info.gift.next_page**: Indicates if more gift data is available
</Accordion>

<Accordion title="Viewer & Engagement Data">
- **live_info.viewers.num**: Peak viewer count
- **live_info.viewers.active**: Active viewers during stream
- **live_info.viewers.is_excitement**: Excitement mode status
- **live_info.comments.num**: Total comments count
- **live_info.comments.users**: Unique commenting users
</Accordion>

<Accordion title="User & Screenshot Data">
- **users**: Array of active users with comment counts and avatars
- **live_info.screenshot**: Screenshot capture information
- **live_info.date**: Stream start and end timestamps
- **live_info.duration**: Stream duration in milliseconds
</Accordion>

</Accordions>

## Advanced Examples

### Analyze Gift Data

```javascript
const jkt48Api = require('@jkt48/core');

async function analyzeGifts(liveId) {
  try {
    const apiKey = 'your-api-key-here';
    const detail = await jkt48Api.recentDetail(liveId, apiKey);
    
    // Calculate total earnings
    const totalPoints = detail.live_info.gift.list.reduce((sum, gift) => 
      sum + (gift.point * gift.num), 0
    );
    
    console.log(`Stream: ${detail.room_info.nickname}`);
    console.log(`Total Points: ${totalPoints}`);
    console.log(`Total Gifts: ${detail.total_gifts}`);
    
    // Top gift types
    const topGifts = detail.live_info.gift.list
      .sort((a, b) => (b.point * b.num) - (a.point * a.num))
      .slice(0, 5);
    
    console.log('\nTop 5 Gift Types by Value:');
    topGifts.forEach(gift => {
      const totalValue = gift.point * gift.num;
      console.log(`${gift.name}: ${totalValue} points (${gift.num} × ${gift.point})`);
    });
    
  } catch (error) {
    console.error('Error analyzing gifts:', error.message);
  }
}

// Usage
analyzeGifts('125470641754483379');
```

### Track User Engagement

```javascript
async function analyzeUserEngagement(liveId) {
  try {
    const apiKey = 'your-api-key-here';
    const detail = await jkt48Api.recentDetail(liveId, apiKey);
    
    const { viewers, comments } = detail.live_info;
    const users = detail.users;
    
    // Calculate engagement metrics
    const commentRate = (comments.num / viewers.num * 100).toFixed(2);
    const activeRate = (viewers.active / viewers.num * 100).toFixed(2);
    
    console.log(`Stream: ${detail.room_info.nickname}`);
    console.log(`Peak Viewers: ${viewers.num}`);
    console.log(`Active Viewers: ${viewers.active} (${activeRate}%)`);
    console.log(`Total Comments: ${comments.num}`);
    console.log(`Comment Rate: ${commentRate}% comments per viewer`);
    console.log(`Unique Commenters: ${comments.users}`);
    
    // Top commenters
    const topCommenters = users
      .sort((a, b) => b.comments - a.comments)
      .slice(0, 5);
    
    console.log('\nTop 5 Commenters:');
    topCommenters.forEach((user, index) => {
      console.log(`${index + 1}. ${user.name}: ${user.comments} comments`);
    });
    
  } catch (error) {
    console.error('Error analyzing engagement:', error.message);
  }
}
```

### Extract Gift Timeline

```javascript
async function getGiftTimeline(liveId) {
  try {
    const apiKey = 'your-api-key-here';
    const detail = await jkt48Api.recentDetail(liveId, apiKey);
    
    // Extract all gifts with timestamps
    const allGifts = [];
    
    detail.live_info.gift.log.forEach(userLog => {
      userLog.gifts.forEach(gift => {
        allGifts.push({
          userId: userLog.user_id,
          giftId: gift.id,
          quantity: gift.num,
          timestamp: new Date(gift.date),
          userTotal: userLog.total
        });
      });
    });
    
    // Sort by timestamp
    allGifts.sort((a, b) => a.timestamp - b.timestamp);
    
    console.log(`Gift Timeline for ${detail.room_info.nickname}:`);
    allGifts.forEach(gift => {
      const time = gift.timestamp.toLocaleTimeString();
      console.log(`${time}: ${gift.giftId} × ${gift.quantity}`);
    });
    
    // Calculate gift frequency
    const streamDuration = detail.live_info.duration / 1000 / 60; // minutes
    const giftFrequency = (allGifts.length / streamDuration).toFixed(2);
    console.log(`\nGift Frequency: ${giftFrequency} gifts per minute`);
    
  } catch (error) {
    console.error('Error extracting timeline:', error.message);
  }
}
```

### Monitor Stream Performance

```javascript
async function getStreamPerformance(liveId) {
  try {
    const apiKey = 'your-api-key-here';
    const detail = await jkt48Api.recentDetail(liveId, apiKey);
    
    const duration = detail.live_info.duration / 1000 / 60; // minutes
    const screenshots = detail.live_info.screenshot.list.length;
    
    // Performance metrics
    const metrics = {
      member: detail.room_info.nickname,
      duration: Math.round(duration),
      peakViewers: detail.live_info.viewers.num,
      totalComments: detail.live_info.comments.num,
      totalGifts: detail.total_gifts,
      uniqueCommenters: detail.live_info.comments.users,
      screenshots: screenshots,
      commentsPerMinute: (detail.live_info.comments.num / duration).toFixed(1),
      viewerEngagement: (detail.live_info.viewers.active / detail.live_info.viewers.num * 100).toFixed(1)
    };
    
    console.log('Stream Performance Report:');
    console.log('========================');
    Object.entries(metrics).forEach(([key, value]) => {
      const label = key.replace(/([A-Z])/g, ' $1').toLowerCase();
      console.log(`${label}: ${value}`);
    });
    
  } catch (error) {
    console.error('Error getting performance:', error.message);
  }
}
```
