## What is Member Detail API?

The Member Detail API from @jkt48/core allows you to retrieve comprehensive information about a specific JKT48 member by providing their name. This endpoint provides detailed member data including profiles, social media links, generation information, and current status for a single member.

- Complete member profile with nicknames
- Social media account links (Twitter, Instagram, TikTok, SHOWROOM, IDN)
- Generation and group information
- Profile images and alternative images
- Graduate status tracking
- SHOWROOM integration data

<Callout>
This API endpoint returns data for a specific JKT48 member based on their name, providing detailed information about that individual member.

All features require an API key for authentication and access.
</Callout>

## Data Field Explanations

<Accordions type="single">

<Accordion title="Basic Information">
- **_id**: Unique identifier for the member
- **name**: Full name of the member
- **nicknames**: Array of known nicknames or stage names
- **url**: URL-friendly identifier for the member
- **group**: Group affiliation (e.g., "jkt48")
</Accordion>

<Accordion title="Images & Media">
- **img**: Primary profile image URL (usually from SHOWROOM)
- **img_alt**: Alternative profile image URL (high-quality version)
</Accordion>

<Accordion title="Social Media">
- **socials**: Array of social media accounts with platform titles and URLs
- **idn_username**: IDN Live platform username
</Accordion>

<Accordion title="Status & Generation">
- **generation**: Member's generation (e.g., "gen11-jkt48")
- **is_graduate**: Boolean indicating if the member has graduated
- **sr_exists**: Boolean indicating SHOWROOM account existence
- **room_id**: SHOWROOM room identifier
</Accordion>

</Accordions>

## Advanced Examples

### Search by Different Name Formats

```javascript
const jkt48Api = require('@jkt48/core');

async function searchMemberByName() {
  try {
    const apiKey = 'your-api-key-here';
    
    // Search by nickname
    const feniByNickname = await jkt48Api.memberDetail('Feni', apiKey);
    console.log('Found by nickname:', feniByNickname.name);
    
    // Search by full name
    const feniByFullName = await jkt48Api.memberDetail('Feni Fitriyanti', apiKey);
    console.log('Found by full name:', feniByFullName.name);
    
    // Search by URL-friendly name
    const feniByUrl = await jkt48Api.memberDetail('feni', apiKey);
    console.log('Found by URL:', feniByUrl.name);
    
  } catch (error) {
    console.error('Error searching member:', error.message);
  }
}
```

### Extract Member's Social Media

```javascript
async function getMemberSocialMedia(memberName) {
  try {
    const apiKey = 'your-api-key-here';
    const member = await jkt48Api.memberDetail(memberName, apiKey);
    
    console.log(`\n${member.name} (${member.nicknames.join(', ')})`);
    console.log('Social Media Accounts:');
    
    member.socials.forEach(social => {
      console.log(`  ${social.title}: ${social.url}`);
    });
    
    return member.socials;
  } catch (error) {
    console.error(`Error fetching social media for ${memberName}:`, error.message);
    return null;
  }
}

// Usage
getMemberSocialMedia('Feni');
```

### Member Profile Display

```javascript
async function displayMemberProfile(memberName) {
  try {
    const apiKey = 'your-api-key-here';
    const member = await jkt48Api.memberDetail(memberName, apiKey);
    
    console.log('='.repeat(50));
    console.log(`MEMBER PROFILE: ${member.name}`);
    console.log('='.repeat(50));
    console.log(`Nicknames: ${member.nicknames.join(', ')}`);
    console.log(`Generation: ${member.generation}`);
    console.log(`Group: ${member.group.toUpperCase()}`);
    console.log(`Status: ${member.is_graduate ? 'Graduate' : 'Active'}`);

    console.log(`Alternative Image: ${member.img_alt}`);

    console.error(`Error displaying profile for ${memberName}:`, error.message);
  }
}

// Usage
displayMemberProfile('Feni');
```

### Error Handling for Member Search

```javascript
async function safeMemberSearch(memberName) {
  try {
    const apiKey = 'your-api-key-here';
    const member = await jkt48Api.memberDetail(memberName, apiKey);
    
    if (member) {
      console.log(`✅ Found: ${member.name}`);
      return member;
    } else {
      console.log(`❌ Member '${memberName}' not found`);
      return null;
    }
    
  } catch (error) {
    if (error.message.includes('not found')) {
      console.log(`❌ Member '${memberName}' does not exist`);
    } else if (error.message.includes('API key')) {
      console.log('❌ Invalid API key provided');
    } else {
      console.log(`❌ Error: ${error.message}`);
    }
    return null;
  }
}

// Usage with error handling
const memberNames = ['Feni', 'Aralie', 'NonExistentMember'];
memberNames.forEach(async (name) => {
  await safeMemberSearch(name);
});
```

</Callout>

## Name Search Tips

<Accordions type="single">

<Accordion title="Supported Name Formats">
The API accepts various name formats:
- **Full Name**: "Feni Fitriyanti"
- **Nickname**: "Feni" 
- **URL Format**: "feni"
- **Case Insensitive**: "FENI", "feni", "Feni" all work
</Accordion>

<Accordion title="Best Practices">
- Use nicknames for faster recognition
- Handle case variations in your search
- Implement fuzzy matching for user input
- Cache frequently searched members
</Accordion>

<Accordion title="Error Handling">
- Member not found returns appropriate error
- Invalid API key returns authentication error
- Network issues should be handled with retries
- Always validate input before making API calls
</Accordion>
