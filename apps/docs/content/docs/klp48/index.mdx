## Introduction
JKT48Connect API <span className='text-fd-muted-foreground text-sm'>(JKT48 Connect API)</span> is a **REST API** providing data related to JKT48 and its sister groups. This KLP48 edition specifically focuses on KLP48 data while maintaining the same robust architecture and design principles as our main JKT48Connect API.

JKT48Connect API - KLP48 Edition offers:
<Cards>
<Card icon={<CpuIcon className="text-purple-300" />} title='KLP48-Focused Endpoints'>
Access various KLP48 data through well-defined REST endpoints tailored for KLP48 content.
</Card>
<Card icon={<PanelsTopLeft className="text-blue-300" />} title='Structured Responses'>
Receive consistent JSON responses for easy parsing and usage.
</Card>
<Card icon={<Database />} title='Up-to-Date KLP48 Data'>
Continuously updated KLP48 data, ensuring you get the latest information about the group.
</Card>
<Card icon={<Terminal />} title='No Modules Required'>
Integrate directly using standard HTTP requests from any programming language.
</Card>
</Cards>

### Terminology
**REST API:** A set of architectural principles for designing networked applications. JKT48Connect API follows these principles.
Basic knowledge of HTTP requests and JSON data structures is useful.

## Getting Started
The base URL for all JKT48Connect API - KLP48 Edition requests is `https://v2.jkt48connect.my.id`.

### Examples
Here are some common KLP48-specific endpoints:
- **KLP48 Members Data:**
  `GET /api/klp48/members`
- **KLP48 Schedule:**
  `GET /api/klp48/schedule`
- **KLP48 News:**
  `GET /api/klp48/news`

### Enjoy!
Start sending requests to the API and integrate KLP48 data into your projects!
