## Introduction

The JKT48Connect Live API provides **real-time data** on JKT48 members currently **live across various platforms** (YouTube, IDN Live, SHOWROOM). It’s designed for quick and easy integration into applications needing instant live status updates.

<Callout title="What this API offers">
  This Live API gives you cross-platform coverage, real-time updates, and detailed live data, all through simple HTTP requests.
</Callout>

### Terminology

**API Key:** A unique key required for authenticating your requests.
**Endpoint:** The specific URL path for accessing a particular API resource.

---

## Getting Started

The base URL for all JKT48Connect API requests is `https://v2.jkt48connect.my.id`.

### Endpoint

To retrieve live JKT48 member data, use the following endpoint:

`GET /api/jkt48/live`

### Authentication

This endpoint requires an **API Key** for access. Append `?apikey=YOUR_API_KEY` to your request URL. You can obtain your API key from the [official JKT48Connect website](https://www.jkt48connect.my.id/buyapi).

**Example Request:**
`GET https://v2.jkt48connect.my.id/api/jkt48/live?apikey=YOUR_API_KEY`

Remember to replace `YOUR_API_KEY` with your actual API key.

ENDPOINT = '/api/jkt48/live'

    try:

        response.raise_for_status()  # Raise an exception for HTTP errors
        data = response.json()
        print(data)

        print(f"Error fetching live members: {e}")

if __name__ == "__main__":
    get_live_members()

<TabsContent value="go">
```go
package main
import (
"encoding/json"
"fmt"
"io/ioutil"
"net/http"
)
const (
	apiKey  = "YOUR_API_KEY" // Get your API key from [https://www.jkt48connect.my.id/buyapi](https://www.jkt48connect.my.id/buyapi)
	baseURL = "[https://v2.jkt48connect.my.id](https://v2.jkt48connect.my.id)"
	endpoint = "/api/jkt48/live"
)

type LiveMember struct {
	Name            string `json:"name"`
	Img             string `json:"img"`
	ImgAlt          string `json:"img_alt"`
	URLKey          string `json:"url_key"`
	Slug            string `json:"slug"`
	RoomID          int    `json:"room_id"`
	IsGraduate      bool   `json:"is_graduate"`
	IsGroup         bool   `json:"is_group"`
	ChatRoomID      string `json:"chat_room_id"`
	StartedAt       string `json:"started_at"`
	StreamingURLList []struct {
		Label   string `json:"label"`
		Quality int    `json:"quality"`
		URL     string `json:"url"`
	} `json:"streaming_url_list"`
	Type string `json:"type"`
}

func main() {
	url := fmt.Sprintf("%s%s?apikey=%s", baseURL, endpoint, apiKey)

	resp, err := http.Get(url)
	if err != nil {
		fmt.Printf("Error fetching live members: %v\n", err)
		return
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		fmt.Printf("HTTP Error: %d %s\n", resp.StatusCode, resp.Status)
		return
	}

	body, err := ioutil.ReadAll(resp.Body)
	if err != nil {
		fmt.Printf("Error reading response body: %v\n", err)
		return
	}

	var liveMembers []LiveMember
	err = json.Unmarshal(body, &liveMembers)
	if err != nil {
		fmt.Printf("Error unmarshaling JSON: %v\n", err)
		return
	}

	for _, member := range liveMembers {
		fmt.Printf("Name: %s, Type: %s, URL: %s\n", member.Name, member.Type, member.StreamingURLList[0].URL)
	}
}
```
